## 🏃 Quickstart

### 1. Start the Backend Runtime Server
```bash
cd server
npm install
node src/index.js
```
*Runs at `http://localhost:4000` with WebSocket telemetry at `ws://localhost:4000`.*

### 2. Start the Frontend Control Center
```bash
cd client
npm install
npm run dev
```
*Open `http://localhost:3000` in your browser.*
